# C++ Support for Neovim

## Goal

Enable full C++ language support in Neovim: autocomplete, formatting, code suggestions, diagnostics, go-to-definition, and syntax highlighting.

## Context

The kickstart.nvim config already ships with the plugin infrastructure (Mason, nvim-lspconfig, conform.nvim, Treesitter, blink.cmp). C++ support requires wiring `clangd` and C++-specific tools into each layer. `clangd = {}` was already present as a commented-out example in the servers table.

## Design

- **LSP**: `clangd` with `--background-index` and `--clang-tidy` flags for fast indexing and inline static analysis.
- **Formatting**: `clang-format` via conform.nvim for format-on-save.
- **Syntax highlighting**: Treesitter parser for `cpp` (the `c` parser was already included).
- **Linting**: Handled by clangd's built-in diagnostics and `--clang-tidy`; no separate linter plugin needed.
- **Tool management**: Mason auto-installs `clangd` and `clang-format`.

## Edge Cases / Risks

- A C++ compiler (clang or gcc) must be installed on the system for clangd to work.
- For best results, projects should have a `compile_commands.json` (generated by CMake, Bear, or similar) so clangd can resolve include paths and build flags.
- `clang-format` uses a `.clang-format` file if present; without one it falls back to LLVM style defaults.

## Testing

- Open a `.cpp` file and verify syntax highlighting works (Treesitter).
- Type code and confirm autocomplete suggestions appear (clangd + blink.cmp).
- Save a file and confirm it is auto-formatted (conform.nvim + clang-format).
- Use `grd` to go-to-definition, `grr` for references.
- Run `:Mason` and verify `clangd` and `clang-format` are installed.
- Run `:checkhealth` and verify no errors for LSP/Treesitter.
